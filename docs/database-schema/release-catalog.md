# Release catalog

The release catalog (`apps/web/src/server/release-catalog/`) keeps each app release's notes. It is
self-contained so it can move to its own service: its table has no foreign key to, and is never
joined with, any CoForge domain table. Migration `20261019120000_release_catalog_releases`.

`release_catalog_releases` — one row per released app version:

| Column | Type | Notes |
| --- | --- | --- |
| `id` | UUID | UUIDv7 primary key, generated by the Prisma client. |
| `app` | TEXT | App slug, `^[a-z0-9][a-z0-9-]{0,62}$` (e.g. `coforge-computer`). |
| `version` | TEXT | Release version in full (`0.1.4`, `0.1.4-dev.2`). |
| `notesEn` | TEXT | English Markdown notes, trimmed, 1 to 16000 characters. |
| `notesZhCn` | TEXT | Simplified Chinese Markdown notes, same limits. |
| `createdAt` | TIMESTAMP(3) | First publish. |
| `updatedAt` | TIMESTAMP(3) | Last publish; a later publish overwrites both notes. |

Unique (`app`, `version`): a publish upserts on it. Rows are never deleted by the Web.
